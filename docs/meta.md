# Метапрогрессия «Верстак» (этап 1)

Сила игрока между миссиями: коллекция деталей башен, кампания-лесенка карт,
сундуки за прогресс. Вдохновение — коллекционные режимы custom-игр (DOTA TD
Fair Play Mode, Monkey Knowledge из Bloons): после катки игрок получает
запчасти, которые усиливают конкретные башни в следующих миссиях.

Задача закрывает прогрессию «каждая карта сложнее предыдущей»: карта нельзя
усилить изнутри бесконечно — мета-сила компенсирует растущие волны.

## Кампания-лесенка

- Карты открываются по цепочке в порядке реестра `MAP_DEFS`:
  Пограничный тракт → Старая мельница → Каменный мост → Заброшенные шахты →
  Ледяной перевал → Пепельная долина.
- Первая карта открыта всегда; победа на карте открывает следующую.
- Каждая карта сложнее предыдущей не только фичей, но и явным множителем
  HP заражённых `MapDef.hpMult`: 1.00 / 1.08 / 1.16 / 1.24 / 1.32 / 1.40.
  Это отдельная ось от сложностей (Новобранец/Ветеран/Кошмар множат HP
  дополнительно) — лесенка видна и в коопе, и на любой сложности.

## Детали башен (коллекция)

- У каждой из 15 боевых башен три слота деталей: **урон**, **скорострельность**,
  **дальность**. Детали копятся единицами (`units`), каждая единица — фиксированная
  прибавка, есть потолок (cap). Плоские множители «всему сразу» не делаем —
  коллекция должна собираться в «свой билд».
- Бонусы малые: урон +1.5%/ед. (до +15%), скорострельность −1%/ед. к интервалу
  (до −10%), дальность +1%/ед. (до +5%). Никакой крит-инфляции: максимальная
  собранная башня сильнее базовой примерно на 15–20% — этого хватает, чтобы
  «дожать» следующую карту, но не сломать баланс ранних.
- Экономические постройки (стан/шахта/бур) и слитые уникальные башни вне
  коллекции: слитые и так — вершина ветки, экономика усиливается лавкой.
- Применение: движок умножает урон/интервал/дальность башни на факторы
  коллекции (`Game.metaBonus`, колбэк от UI). В коопе мета выключена
  (fair play: у игроков разные коллекции — сравнивать их нечестно).

## Сундуки

Источники:

| Источник | Когда | Содержимое |
|---|---|---|
| Первое прохождение карты | гарантированно при победе | 3–5 деталей |
| Повторная победа | шанс 25% | 1–3 детали |
| Ежедневная катка | 1 сундук в день за любую завершённую миссию | 2–4 детали |
| Ачивки | этап 2 (спроектировано) | — |
| Донат-сундук | **зарезервировано** (монетизация, не реализовано) | — |

Дроп: единицы деталей на случайную боевую башню и случайный слот; вес
«полезных» стартовых башен чуть выше, чтобы прогресс первых карт ощущался.

## Хранение

`localStorage`-ключ `zr-meta`, версия схемы `v: 1`:

```ts
{
  v: 1,
  parts: Record<string, number>,      // «archer-damage» → единиц
  unlocked: string[],                 // id открытых карт, ['tract', ...]
  dailyAt: number | null,             // метка последнего ежедневного сундука
  wins: number,                       // всего побед
  winsByMap: Record<string, number>,  // побед по картам
}
```

Читается только в браузере (SSR-безопасно: движок получает данные через
колбэк, headless-симулятор живёт без мета — это базовая линия баланса).

## Этапы

1. **Этап 1 (готово):** лесенка карт + множитель HP, детали трёх слотов,
   сундуки за карту/день, Верстак в меню, замки в выборе карты, награда на
   экране победы, тесты.
2. **Этап 2 (готово):** ачивки-сундуки (6 одноразовых: «Идеальная оборона»,
   «Мастер слияний», «Кошмар удержан», «Все тракты», «Ветеран горизонта»,
   «Полный комплект»), визуал сундуков (иконка/акцент у каждого типа,
   карточки-«трофеи миссии» на экране победы), имена билдов (кнопка ✎ в
   коллекции ПРОФИЛЯ), список ачивок в ПРОФИЛЕ.
3. Этап 3: донат-сундуки (дизайн-заготовка: пул как у ежедневного, отдельная
   валюта, никакой силы вне пула деталей — fair play).
