## Новый флоу (карта экранов)

1. **Хаб «Командный пункт лагеря»** — главный экран:
   - центр: арт-логотип (существующий) + плашка прогресса (последняя карта, лучший результат из meta);
   - сектора-панели: **КАМПАНИЯ**, **ПРОФИЛЬ**, **СОБЫТИЯ**, **НАСТРОЙКИ**;
   - фон: живой изометрический мир (как сейчас) — сохранить;
   - углы: слайдер громкости (существующий), версия.
2. **Карта кампании** (открывается сектором КАМПАНИЯ):
   - 6 узлов = 6 карт-биомов с превью (существующие превью карт), бейджи прогресса, лок-состояние (`isMapUnlocked`);
   - клик по узлу → модалка миссии.
3. **Модалка миссии**:
   - превью карты и биом, **сегменты сложности** (Новобранец/Ветеран/Кошмар), **витрина героев** (4 SVG-портрета `AvatarImg`);
   - кнопки: НАЧАТЬ / ОТМЕНА (+ кооп-ссылка — вопрос №2 ниже).
4. **Панель СОБЫТИЯ**: карточки ежедневок с таймером (`dayKey`, `dailyReady`, `chestForDaily` из `src/game/meta.ts`).
5. **Панель ПРОФИЛЬ**: статистика (`wins`, `winsByMap`, слипания/коллекция `collectionRows`), сброс прогресса.

## Технически

- Переписать `src/components/td/MainMenu.tsx` с нуля; сохранить контракты: запуск миссии, `loadMeta/saveMeta`, кооп-режим (если остаётся), работу со звуком меню.
- Анимации панелей/модалок: `framer-motion` (уже в зависимостях).
- Визуал: латунные рамки/заклёпки/шкалы в стиле существующих SVG-портретов (`public/assets/portraits/`), палитра из `docs/art-prompts.md`.
- Проверки после сборки: `tsc --noEmit`, eslint, ручной прогон в браузере (ПК + узкий viewport).

## Открытые вопросы — РЕШЕНО (13.11.2026, ответы пользователя)

1. **Герой** — выбирается **после выбора карты**, внутри модалки миссии. На главном экране витрины героя нет.
2. **Кооп** — инвайт-кнопка на главном экране: **внизу слева мини-профиль игрока, справа от него — кнопка «+»** для приглашения другого игрока (создание/ввод ссылки-приглашения). Званый игрок отображается рядом с профилем.
3. **Ежедневки** — **и награда за вход, и задачи дня** («победи N карт» и т.п.).
4. **Workbench** — **убрать совсем** (витрина башен из текущего меню не переносится).
