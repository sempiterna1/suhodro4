## Как работает извлечение

```bash
node scripts/extract-tower-arts.mjs
```

- Исходники: `C:/Users/magic/Desktop/TD` (листы 1024×1024, один лист = одна башня).
- Кадрирование задаётся в массиве `SHEETS`: `[файл, id, left%, top%, right%, bottom%]`.
  Рамка должна быть тесной вокруг башни с пьедесталом, без панелей интерфейса.
- Фон определяется по среднему цвету углов и заливается от кромки кадра.
- Замкнутые «дыры» фона (например, между тетивой и корпусом) удаляются отдельным
  проходом с более строгим порогом `T_HOLE` (по умолчанию 12), чтобы не съедать
  тёмные текстурные стены.
- Берётся крупнейшая связная компонента — это отсекает искры, дым и выносные
  эффекты. Затем эрозия альфы 1 px против JPEG-ореола, обрезка по bbox и
  уменьшение до высоты 140 px.
- Пороги можно переопределить переменными окружения `T`, `TH`, `HOLE`
  (см. начало скрипта).
- Скрипт печатает итоговые размеры `crop`/`out`. После генерации PNG нужно
  вручную добавить/обновить запись в `src/game/assets.json` (`w`, `h`, `ax` —
  `ax` измеряется по нижним строкам альфы, скрипт его не пишет).
